THE USEFUL DETAILS

Before you dive in.

Connections, installation, and keeping things up to date.

Read the project docs ↗
Which AI connections can I use?+

NativeAgent supports ChatGPT and Grok account connections, Claude API, and custom compatible APIs. Available models and features depend on your integration. Native AI reviews use supported account connections or APIs; Claude account-only sessions run through the official Claude Code terminal. Provider subscriptions and API usage are separate from the app.

How do I connect GitHub?+

Install the official GitHub CLI, then open Settings → GitHub in NativeAgent and sign in through GitHub. Credentials are managed by GitHub CLI. From there, clone or create repositories, review changes, commit, push, compare branches, and merge pull requests.

How do I install NativeAgent?+

Download and open the DMG, then drag NativeAgent onto the Applications folder in the installer window. Open NativeAgent from Applications and eject the disk image. When replacing an older copy, quit the app first and choose Replace. Your chats and settings stay intact.

Already installed? Here’s how to update.+

Choose NativeAgent → Check for Updates… or open Settings → Updates. The updater replaces your existing app in place and keeps your chats and settings. You can also configure automatic checks and downloads. Active tasks and unsaved edits postpone an updater-requested restart.

Where are my conversations stored?+

Your conversation history is stored locally on your Mac. Requests and selected context are sent to the AI provider you use. Bookmarks, archive search, date filters, and storage controls help you manage your library.
